# 114 年建築師考試資料

## 考古題練習網站

直接以瀏覽器開啟 `index.html`。網站提供四科共 240 道選擇題的逐題、隨機、錯題與計時練習，並提供兩科申論題和兩科設計題的原卷連結及本機作答筆記。選擇答案後立即顯示對錯與可給分答案，每題以首次作答計分；交卷後也能逐題核對，並查看官方標準答案及更正 PDF。答案以檔案內的更正公告優先；含圖題須查看原卷 PDF。成績與筆記儲存在目前瀏覽器，清除瀏覽器資料後可能消失。`data.js` 由 `build_data.py` 從下方 PDF 產生。
